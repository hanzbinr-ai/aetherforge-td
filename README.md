# Aetherforge TD Prototype

Simple Stone Age Tower Defense prototype.

## How to Play
1. Open `index.html` in a browser.
2. Click a tower button, then click on the map to place it.
3. Press **Start Wave**.
4. Protect the base.

## Current Features
- Basic path
- 2 towers (Totem Api & Tanaman Beracun)
- Simple projectiles and animations
- Waves
- Resource from kills

This is an early prototype based on the Aetherforge design.
